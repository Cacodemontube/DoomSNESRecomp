# DoomSNESRecomp v0.04

- Improved rendering performance through cached texture decoding, prepared
  geometry and parallel rendering.
- Automatic camera-worker recovery after temporary overload.
- Smoother slow turning and improved camera interpolation.
- Fixed widescreen geometry seams and missing edges at native resolution.
- Fixed sprite flickering on cached widescreen frames.
- Added optional PC enemy/projectile rotations, monster infighting and an
  auto-aim crosshair.
- Corrected sprite identity and Spiderdemon walking-frame orientation.
- Windows launches without a separate command window.

Extract the complete archive and run DoomSNESRecomp. Select your own
**Doom (USA).sfc** ROM. Display and gameplay enhancements are available in Mods.
PC rotations require your own full **Doom/Ultimate Doom DOOM.WAD**.

Supported platforms: Windows x64 and x86, Linux x64, macOS Apple Silicon
and macOS Intel.

Performance depends on hardware and the selected resolution, aspect ratio
and presentation rate. Keep the previous version available for comparison.
